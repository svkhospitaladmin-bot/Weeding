# कि ✦ रु · Wedding Invitation

## Website

https://svkhospitaladmin-bot.github.io/Weeding/

Static website: publish the `main` branch from the repository root in GitHub Pages settings.

## Update

Edit `index.html`, `style.css` and `app.js`. Keep filenames and letter case unchanged. Push changes to `main` to update the website.
